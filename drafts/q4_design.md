## STEP 1

- **stage**: "STEP 1"
- **label**: "画質が違うと何GB変わる？"

**question（改行は \n）**
```
ハルカは毎日YouTubeを1時間見るつもりだ。\n標準画質（480p）では1時間あたり約0.5GBのデータを使う。\n\nところで、ハルカのお父さんは「YouTubeは画質を上げると通信量がグッと増えるぞ」と言っていた。\nもしハルカが標準画質（0.5GB/時間）ではなく、高画質（HD・1080p＝2GB/時間）で毎日1時間見た場合、\n1ヶ月（30日）の使用量は標準画質と比べて何GB多くなるか？
```

**hint**
```
それぞれの画質で1ヶ月分の使用量を計算して、その差を求めてみよう。
```

**choices**
| label | value | correct |
|-------|-------|---------|
| A | 30GB | false |
| B | 40GB | false |
| C | 45GB | true |
| D | 60GB | false |

**explanation（改行は \n）**
```
標準画質：0.5GB×30日＝15GB\n高画質（HD）：2GB×30日＝60GB\n差は 60－15＝45GB。\n\n画質を上げるだけでこんなに差が出るんだ！\nハルカは標準画質（15GB/月）で使うことにした。\nこの15GBをもとに、次は料金を計算していこう。
```

- **label**: "プランAで計算してみよう"

**question（改行は \n）**

```

**hint**

```

**choices**

|-------|-------|---------|
| A | 2,800円 | false |
| B | 3,000円 | false |
| C | 3,500円 | false |

**explanation（改行は \n）**
```
使用量にかかる料金：200円×15GB＝3,000円\n基本料を足すと：800＋3,000＝3,800円。\n他にもっといいプランはないだろうか？
```

## STEP 3

- **stage**: "STEP 3"
- **label**: "3つのプランを比べて最安を探せ！"

**question（改行は \n）**
```
さらに調べると、あと2つのプランが見つかった。\n\n・プランB：月額2,000円・8GBまで込み／8GB超過分は150円/GB追加\n・プランC：月額3,200円で使い放題\n\n15GB使ったとき、3つのプランの中でハルカに一番お得なのはどれか？
```

**hint**
```
プランBの料金を計算してみよう。8GBを超えた分（7GB）に150円をかけて、月額2,000円に足すといくらになる？
```

**choices**
| label | value | correct |
|-------|-------|---------|
| A | プランA（3,800円） | false |
| B | プランB | true |
| C | プランC（3,200円） | false |
| D | わからないので契約しない | false |

**explanation（改行は \n）**
```
まずプランBを計算しよう。\n超過分：15－8＝7GB\n追加料金：7×150円＝1,050円\n合計：2,000＋1,050＝3,050円\n\n3プランを並べると…\n\n🥇 プランB：3,050円 ← これが正解！\n🥈 プランC：3,200円（差額わずか150円…惜しい！）\n🥉 プランA：3,800円\n\n「基本料が安いから！」と飛びついたプランA、実は一番高かった。基本料だけ見て決めると痛い目を見るぞ！😅\n\n……でも、ちょっと待てよ。\n\nプランBとプランCの差はたった150円。\nあと1GBでも使用量が増えたら、あっという間に逆転する。\n\nスマホの料金プランは「今の使い方」だけじゃなく\n「これからの使い方」も考えて選ぶのが本当の正解かもしれない。
```
